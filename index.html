02 / THE PROBLEM

ATTENTION HAS A GROWING MEMORY BILL

Standard Softmax couples every token to all previous tokens. In autoregressive inference, the KV-Cache must store all keys and values, scaling memory with sequence length \(N\).

Standard Softmax Attention Complexity: \( \mathcal{O}(N^2 \cdot d) \)
\[ \text{Attn}(Q, K, V) = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d}}\right) V \]

Non-linear Softmax couples keys and values inside \(\exp(Q K^T)\). Terms cannot be reordered, forcing explicit computation: standard attention forms an \(N \times N\) attention score matrix. This toy uses \(N \times N\) as a simplified pairwise interaction count.

Linear Kernel Attention Complexity: \( \mathcal{O}(N \cdot d^2) \)
\[ \text{LinearAttn}(Q, K, V) = \frac{\phi(Q) \left( \phi(K)^T V \right)}{\phi(Q) \left( \phi(K)^T \mathbf{1} \right)} \]

By substituting a kernel dot product \(\phi(q)^T \phi(k)\), matrix multiplication becomes associative: \(\phi(K)^T V\) collapses sequence length into a constant \(d \times d\) state matrix \(S_t\).

06 / FRONTIER RESEARCH

FROM ATTENTION TO MEMORY: THE BDH CONNECTION

How does linear attention connect to modern Post-Transformer architectures? Pathway's Dragon Hatchling (BDH) and BDH-CQ reframe attention as dynamic synaptic plasticity.

[DIRECT RESEARCH EVIDENCE: Katharopoulos et al., 2020]

Kernel Reassociation Unlocks Recurrence

By decomposing attention similarity as \(\text{sim}(q, k) = \phi(q)^T \phi(k)\), matrix associativity allows factoring \(\phi(q_i)\) out of the summation:

\[ O_i = \frac{\phi(q_i)^T \left( \sum_{j=1}^i \phi(k_j) v_j^T \right)}{\phi(q_i)^T \left( \sum_{j=1}^i \phi(k_j) \right)} = \frac{\phi(q_i)^T S_i}{\phi(q_i)^T z_i} \]

Complexity transforms from \(\mathcal{O}(N^2 \cdot d)\) pairwise matrix multiplication into an \(\mathcal{O}(N \cdot d^2)\) recurrent state update.

➔ Reassociate ➔
Linear Attention
\( \phi(Q) \times (\phi(K)^T \times V) \)
\([N \times d] \times [d \times d]\)
[CONCEPTUAL RELATION: Schlag et al. 2021, Ba et al. 2016]

Linear Attention as Fast-Weight Memory

Schlag, Irie, and Schmidhuber (NeurIPS 2021) established that Linear Transformers are mathematically equivalent to Fast Weight Programmers (FWPs):

\[ W_t = W_{t-1} + \eta_t \cdot \phi(k_t) \otimes v_t^T \]

The outer product \(\phi(k_t) v_t^T\) acts as a Hebbian associative write: pre-synaptic activation \(\phi(k_t)\) and post-synaptic signal \(v_t\) adjust connections in fast synaptic memory.

07 / SCIENTIFIC HONESTY

WHAT THIS DEMO DOES NOT PROVE

Scientific credibility requires stating honest limitations. Linear attention and Transformers occupy different trade-offs on the computational Pareto frontier.

⚠️

1. Toy Educational Substrate

The computation running on this page is a 4-dimensional toy feature substrate designed for pedagogical transparency, not a full multi-head, multi-layer production LLM.

[PEDAGOGICAL TOY]
⚠️

2. Finite Capacity & Associative Interference

Compressing an unbounded sequence into a fixed \(d \times d\) matrix causes earlier associations to degrade over long contexts without decay gating or memory eviction.

[CAPACITY BOTTLENECK]
⚠️

3. Softmax Sharpness Loss

Softmax attention applies an exponential \(\exp(q^T k)\), creating sharp focus on isolated outlier tokens. Linear attention feature maps produce flatter retrieval distributions.

[RETRIEVAL DILUTION]
⚠️

4. Hardware & FlashAttention Realities

Theoretical \(\mathcal{O}(N)\) complexity does not automatically imply faster wall-clock execution. For short sequences (\(N \le 2048\)), FlashAttention's SRAM tiling often outperforms recurrent scans on modern GPUs.

[HARDWARE BOTTLENECK]
⚠️

5. Scoped BDH Analogy

The connection to BDH-CQ is an architectural analogy illustrating recurrent associative accumulation. It does not prove the benchmark performance of Pathway's full production models.

[SCOPED ANALOGY]
⚠️

6. No Universal Superiority Claim

Neither architecture is universally superior. Linear attention trades away exponential softmax sharpness in exchange for constant decoding memory footprint.

[PARETO TRADE-OFF]

60-SECOND HACKATHON SYNTHESIS

Can You Explain Linear Attention in 60 Seconds?

01:00

Linear attention is not a vague approximation. It is an exact sequence of 4 physical operations:

STEP 1
TOKENS (\(x_t\))
Incoming token arrives as vector \(x_t \in \mathbb{R}^d\). No past keys or values need to be reloaded into GPU high-bandwidth memory.
➔
STEP 2
UPDATE (\(\Delta S_t\))
Compute rank-1 outer product \(\Delta S_t = \phi(k_t) \otimes v_t^T\). Acts like a local Hebbian fast-weight synaptic write.
➔
STEP 3
STATE (\(S_t\))
Accumulates in-place: \(S_t = S_{t-1} + \Delta S_t\). Constant \(d \times d\) memory footprint regardless of sequence length \(N\).
➔
STEP 4
QUERY (\(y_t\))
Probe query extracts answer in \(\mathcal{O}(1)\) time via single vector-matrix dot product: \(y_t = \frac{\phi(q_t)^T S_t}{\phi(q_t)^T z_t}\).
✓ Synthesis Validated: “Tokens ➔ Update ➔ State ➔ Query. That is why Linear Attention eliminates the growing KV-cache memory bill.”
